parseRawEntry() — foto_urls parser (S13)

function parseRawEntry(raw: any): { src: string; uploadedAt: string; uploaderEmail: string; fileName: string; kind: string } {
  const empty = { src: '', uploadedAt: '', uploaderEmail: '', fileName: '', kind: 'image' }
  if (!raw) return empty
  let obj: any = raw
  if (typeof raw === 'string') {
    const t = raw.trim()
    if (t.startsWith('{')) { try { obj = JSON.parse(t) } catch { return empty } }
    else if (t.startsWith('http')) return { src: t, uploadedAt: '', uploaderEmail: '', fileName: '', kind: 'image' }
    else return empty
  }
  return {
    src: obj['url'] || obj['src'] || '',
    uploadedAt: obj['data'] || obj['uploadedAt'] || obj['date'] || '',
    uploaderEmail: obj['email'] || '',
    fileName: obj['fileName'] || '',
    kind: obj['kind'] || 'image',   // legacy entries default to image
  }
}

displayName() helper

function displayName(email: string): string {
  const a = anetaret.find(m => m.email === email)
  if (a?.profiles?.emri && a?.profiles?.mbiemri) return `${a.profiles.emri} ${a.profiles.mbiemri}`
  if (a?.profiles?.emri) return a.profiles.emri
  return email.split('@')[0]  // fallback
}

fileType() helper

function fileType(file: File): 'image' | 'pdf' | 'doc' | 'other' {
  if (file.type.startsWith('image/')) return 'image'
  if (file.type === 'application/pdf' || file.name.endsWith('.pdf')) return 'pdf'
  if (file.name.endsWith('.doc') || file.name.endsWith('.docx') ||
      file.name.endsWith('.xls') || file.name.endsWith('.xlsx')) return 'doc'
  return 'other'
}

Prerje Plani — Plan Crop Tool

NEW S13 ✓

A fullscreen modal (position: fixed, inset: 0) for cropping a section of the project plan PDF and attaching it as an image to a task thread. Modeled on Fieldwire's "Crop Plan" feature.

Architecture

ComponentDetail
PDF renderingpdfjs-dist 3.11.174 via CDN. workerSrc from cdnjs. Page rendered to offscreen canvas at baseScale (fit-to-container). Re-renders at new scale after 150ms debounce when zoom changes.
Smooth zoomImmediate visual feedback: drawImage(offscreen, px, py, scaledW, scaledH) — stretches existing render instantly. Re-render fires after zoom stops. No flicker.
Crop boxFixed in screen/canvas pixel space (not PDF space). Starts at 55% width × 55% height, centred. PDF moves and zooms behind it.
8 handles4 corners (nw/ne/sw/se) + 4 edge midpoints (n/s/e/w). Each handle resizes only its edge(s). HIT_RADIUS = 20px for touch friendliness.
Interaction modelDrag on handle → resize crop box. Drag anywhere else → pan PDF. Scroll wheel / pinch-to-zoom → zoom PDF. Crop box never moves unless explicitly dragging a handle. Single finger on iPad = pan PDF.
Output qualityAt crop time: re-render PDF at 3× current scale. drawImage from hi-res canvas → output JPEG at 0.95 quality.
Auto-select planIf selectedTask.plan_id matches a plan in availablePlans, that plan is pre-selected. Falls back to availablePlans[0].
Plan switcherDropdown appears in header only if project has multiple plans.
Saved asUploaded to foto-kantier bucket at {taskId}/{timestamp}-crop.jpg. Saved as { kind: 'image', fileName: 'Prerje — PlanName', ... } in foto_urls.

Critical Rules — Never Break

STABLE
RuleDetail
NONever call loadData() after field saves — Race condition, dates snap back. Update local state with setSelectedTask + setDetyrat instead.
NODate inputs save on onChange, not onBlur — onBlur races with loadData() re-fetch.
NONo sed on TypeScript files — sed breaks on special chars. Use str_replace tool only.
NONo template literals in JSX <option> text — Turbopack build fails.
NOconfirm() is blocked on Vercel — Use inline state-based confirmation UI instead.
NOMultiple file uploads at once — overwrite each other. Wait for line count confirmation.
NONever use str_replace on strings that appear more than once — causes wrong replacement. Always verify uniqueness first.
YESparams.id must be typed — const projektId = params.id as string. Never inline.
YESRLS policies use user_id = auth.uid() — Email-based RLS fails silently.
YESTrial logic is inlined in each file — Do NOT import from @/lib/trial.
YESfoto_urls parser — handle 3 cases: plain URL string, JSON string starting with {, object. Missing kind → default to 'image'.
YESPDF only, no Word export — Word is editable, defeats ISO 9001 document control.
YESprofiles RLS allows all authenticated reads: CREATE POLICY "profiles_read_all" ON profiles FOR SELECT TO authenticated USING (true);
YESWhen adding new PlanCropModal or large component via str_replace — always verify no old body remains at end of file. Check for } { pattern and trim.
YESLink chips in task thread: entire chip must be an <a> tag with href={entry.src}. Delete button needs e.preventDefault(); e.stopPropagation().

-- RLS policies
DROP POLICY IF EXISTS "projektet_member_read" ON projektet;
CREATE POLICY "projektet_member_read" ON projektet FOR SELECT TO authenticated
  USING (krijuar_nga = auth.uid() OR id IN (
    SELECT projekti_id FROM anetaret WHERE user_id = auth.uid()
  ));

DROP POLICY IF EXISTS "detyrat_member_read" ON detyrat;
CREATE POLICY "detyrat_member_read" ON detyrat FOR SELECT TO authenticated
  USING (projekti_id IN (
    SELECT id FROM projektet WHERE krijuar_nga = auth.uid()
    UNION
    SELECT projekti_id FROM anetaret WHERE user_id = auth.uid()
  ));

-- Auto-fill trigger
CREATE OR REPLACE FUNCTION fill_anetaret_user_id()
RETURNS TRIGGER AS $$
BEGIN
  SELECT id INTO NEW.user_id FROM auth.users WHERE email = NEW.email LIMIT 1;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

CREATE TRIGGER fill_user_id_on_insert
  BEFORE INSERT ON anetaret
  FOR EACH ROW EXECUTE FUNCTION fill_anetaret_user_id();

-- profiles read all
CREATE POLICY "profiles_read_all" ON profiles FOR SELECT TO authenticated USING (true);

Design Decisions

STABLE
DecisionRationale
PDF only, no Word exportWord is editable — defeats ISO 9001 document control purpose
Per-project pricing (not per-user)Construction teams are variable — per-user pricing punishes larger crews
Albanian language firstNo competitor has Albanian localisation. This is the moat.
ISO 9001 document structureGives legitimacy and matches what clients/investors expect
Teardrop pins on planetStandard map pin metaphor — field crews understand immediately
Activity log as jsonb arraySimpler than separate table for MVP, still queryable
caktuar_email stores email stringAllows assignment to invited users before they join platform
foto_urls stores kind + fileNameEnables typed rendering (image thumbnail vs file chip vs link chip) without separate table
Crop box fixed in screen space, PDF pans behindMatches Fieldwire UX — users pan to find location, then resize crop box around it. Inverse (crop in PDF coords) confuses users when zooming.
"Nga Dokumentet" as dok_ref, not file copySingle source of truth — matches Procore/Fieldwire reference model. Prevents stale version attachments.
Inline lightbox on task thread (not router.push)Fieldwire behavior — user stays on task context. Navigate-away loses task scroll position and selection.
